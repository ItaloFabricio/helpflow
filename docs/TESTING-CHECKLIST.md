# Checklist manual de testes

- [ ] Abrir o dashboard e conferir os indicadores.
- [ ] Navegar entre Visão geral e Todos os chamados.
- [ ] Pesquisar por protocolo, título e solicitante.
- [ ] Filtrar por status e prioridade.
- [ ] Alterar ordenação.
- [ ] Navegar entre páginas (crie chamados extras para gerar mais de uma página).
- [ ] Abrir detalhes de um chamado.
- [ ] Alterar status e prioridade e salvar.
- [ ] Adicionar observação ao histórico.
- [ ] Criar chamado com dados válidos.
- [ ] Tentar enviar formulário vazio.
- [ ] Tentar enviar e-mail inválido.
- [ ] Atualizar a página e confirmar persistência.
- [ ] Testar menu mobile em viewport estreita.
- [ ] Testar navegação por teclado e foco visível.
- [ ] Conferir console do navegador.
